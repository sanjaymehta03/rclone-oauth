Google Drive access for my own account

Personal OAuth client — not a service, not available to anyone else.

This page exists to document an OAuth application that I created for my own use. The application is a rclone client ID, which lets the rclone file-sync tool access my own Google Drive from my own computer.

What it does

rclone mounts my Google Drive as a filesystem, so I can read and write my files from the command line and from applications that accept filesystem paths. The Google Drive API is used only to list, read, and write the files in my Drive.

What it is not

  • Not a product or service. Nobody else uses it.
  • Not published to any app store, directory, or marketplace.
  • Not affiliated with, endorsed by, or supported by Google.

Who can sign in

Only me. The OAuth consent screen is configured for personal use, and I am the only test user. The client ID exists so that my own machine can authenticate as my own Google account. Google user data obtained through this application is never shared with any third party.

Summary: one person's rclone client, used to sync that person's files to that person's computer. No data leaves my machine.
