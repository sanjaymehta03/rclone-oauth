Privacy Policy

Google Drive access for my own account — last updated 27 September 2026.

Who runs this

This application is a personal OAuth client that I (Sanjay Mehta) created for my own use. It is not a service. Nobody else has an account, and nobody else can sign in.

What data is accessed

The application uses the Google Drive API to access the contents of my own Google Drive account — specifically, to list, read, and write files so that the rclone file-sync tool can mirror them to my own computer.

The following OAuth scopes are requested:

  • https://www.googleapis.com/auth/drive — read and write files in my Drive.
  • https://www.googleapis.com/auth/docs — read and write Google Docs.
  • https://www.googleapis.com/auth/drive.metadata.readonly — read file and folder metadata.

No other Google data is accessed. The application does not read Gmail, Calendar, Contacts, location, or any other data source.

Where that data goes

Nowhere. Files are transferred between my Google Drive account and my own computer and nowhere else. The application contains no analytics, no telemetry, no advertising, and no third-party server. It does not share, sell, or transfer any Google user data to anyone.

Storage and retention

Authentication tokens are stored locally in a configuration file on my own computer, readable only by me. Files synced by rclone are stored in ordinary directories on my own computer. Nothing is retained by any third party.

Third parties

There are none. This application does not use third-party analytics, advertising or tracking services.

Children

This application is not directed at children and collects no data from anyone.

Contact

Questions about this policy can be raised on this site's repository.
